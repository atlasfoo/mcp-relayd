# Product roadmap

## What it is

Maintainer-provided roadmap for the final local MCP relay product.

## How the project uses it

Phase 1 defines the initial core daemon. Later phases define the native bridge, supervision, administration, OS integration and distribution.

## How to consult it

Read [the vendored PRD](../../vendored/PRD.md). The current request selects phase 1 plus early GitHub Actions build/release distribution.
