# Controlled CLI, embedded greeting, and release installers

## What happened

`mcp-relayd` now has an instance-local urfave/cli v3 command tree. A normal `run` hides technical logs and prints an embedded ASCII greeting plus `Local:` URLs for ready servers. `--verbose` remains JSON-only. `config` writes the example TOML to the default path and refuses to overwrite it. Bash and PowerShell scripts install a checksum-verified GitHub release into `~/.local/bin`.

## Criteria delivered

- `CLI-001` — discoverable, compatible CLI — delivered
- `CLI-002` — normal run output — delivered *(amended 2026-11-01: greeting and server list)*
- `CLI-003` — explicit JSON diagnostics — delivered *(amended 2026-11-01: greeting precedes help and version)*
- `CLI-004` — single error and clean shutdown — delivered
- `CLI-005` — compile-time greeting — delivered
- `CLI-006` — `config` writes the default TOML — delivered

## Decisions and deviations

Help is customized per command instance. Root help uses `CustomRootCommandHelpTemplate`; package globals such as `HelpPrinter` are not assigned. The greeting on `run` is written with the first normal log record, so a usage error stays one line. `config` creates the parent directory at `0700` and the file with `O_EXCL` and `0600`. `present_test.go` and `cmd/mcp-relayd/main_test.go` were updated so version output is the greeting plus the exact version line. No gate check was waived.

## ADR proposals & brain updates
